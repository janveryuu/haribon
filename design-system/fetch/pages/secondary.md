# Fetch secondary-route override

Deck creation, tutor, explore, and play use the same Study Fieldbook Next system as the dashboard, with route-specific hierarchy.

- Desktop favors creation, organization, and longer tutor conversations; mobile favors the next useful action and quick help.
- Keep borders and text on semantic Fetch tokens (`border-border`, `text-muted-foreground`, `bg-card`) so light and dark mode stay tuned independently.
- Use competition only inside Play. Explore and Tutor should remain learning-oriented and non-competitive.
- Use Lucide icons with accessible labels, 44px minimum touch targets, visible focus rings, and reduced-motion-safe transitions.
